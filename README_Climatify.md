# 🌱 Climatify Platform — منصة كلايمتيفاي

منصة **كلايمتيفاي (Climatify)** هي المنصة الرقمية الرسمية الرائدة للعمل المناخي والرقمنة البيئية وتمكين الشباب في منطقة الشرق الأوسط وشمال أفريقيا ودولة الإمارات العربية المتحدة. 
تجمع المنصة بين البرامج والمبادرات المجتمعية، الفعاليات المناخية، المساقات التعليمية مع شهادات معتمدة، فرص العمل والتطوع، وحاسبة البصمة الكربونية والألعاب البيئية، مع بوابات للمدارس والشركاء، ولوحة تحكم للأعضاء ولوحة إدارة محتوى كاملة (CMS).

  - التحقق من عمل كافة صفحات الواجهة بسلاسة تامة في كلا الوضعين (سواء كان Supabase متصلاً أو في وضع العرض التجريبي المحلي).
  - التأكد من حماية مسارات المسؤول (Admin Guard) ومنع غير المصرح لهم من الدخول، والتحقق التام من مطابقة معايير الوصول وسلاسة الحركة والملاحة.
  - اختبار أداء واستقرار النظام بالكامل والتأكد من نجاح كافة الاختبارات الـ 69 واجتياز الـ Build بنجاح تام.

### 17. [2026-10-26] — المراجعة الأمنية والتقنية الشاملة وتوحيد تكامل Supabase
- **توحيد طبقة الـ API (Unified Service Facade)**: تم ربط `apiService` بنمط تفويض شفاف (Transparent Delegation Proxy) ليتصل تلقائياً بـ `supabaseService` عند توفر مفاتيح Supabase، مما أتاح لجميع صفحات المنصة (12 صفحة كاملة) التخاطب مع Supabase بدون الحاجة لكتابة شروط يدوية متكررة.
- **حماية أمنية لقواعد بيانات Supabase (RLS & Privileges)**:
  - إصلاح ثغرة التكرار اللانهائي (Infinite Recursion) في دالة `is_admin()` عبر إضافة `SECURITY DEFINER` وتثبيت `set search_path = public`.
  - سد ثغرة تصعيد الصلاحيات (Privilege Escalation) على جدول `profiles` لمنع أي مستخدم عادي من ترقية حسابه إلى `admin`.
  - إضافة Database Trigger تلقائي `on_auth_user_created` لإنشاء الملف الشخصي والإحصائيات بصلاحية `member` فور تسجيل أي حساب جديد.
- **سد ثغرة تسريب الجلسات (Auth Session Leak Fix)**:
  - إضافة استدعاء `supabase.auth.signOut()` عند تسجيل خروج العضو (`logoutMember`) أو المسؤول (`logoutAdmin`) لمنع استعادة الجلسة السابقة عند تحديث الصفحة من نفس المتصفح.
- **حفظ معرّفات الكيانات (ID Integrity in CMS)**:
  - إصلاح قراءة وإنشاء العناصر في `content_items` لضمان الاحتفاظ بـ `id` داخل الكائن المرجوع وعدم فقدانه، مع تحسين إثراء بيانات المساقات والفعاليات في لوحة تحكم العضو.
- **إضافة ملف المناهج المناخية المفقود**:
  - إنشاء ملف `public/climate-curriculum.pdf` الصالح لمنع حدوث خطأ 404 عند نقر المعلمين أو المدارس على "تحميل المنهج".
- **فحص الجودة والاختبارات**:
  - التحقق من خلو الكود من أخطاء TypeScript وLinting، ونجاح كافة الاختبارات الآلية الـ 69 بنسبة 100% وبناء الـ Production بنجاح.
